Getting started with the command line tool

The command line tool lets you manage projects without opening the dashboard.

Install

pip install exampletool

Sign in

Run the login command and paste the token from your account page. The token is stored in your home directory with owner-only permissions.

exampletool login

Now list your projects with the projects command.
