Release notes: version 2.4

Version 2.4 focuses on faster imports and clearer error messages.

Added

  • CSV import now streams large files instead of loading them into memory.
  • Project owners can transfer a project to another workspace.

Fixed

  • Dates in exports no longer shift by a day for users west of UTC.
  • The search box keeps its text after a failed request.
