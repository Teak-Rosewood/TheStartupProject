List orders

Returns a page of orders for the authenticated account, newest first.

GET /v1/orders?limit=20&status=paid

Query parameters

NameTypeDescription
limitintegerNumber of orders to return, from 1 to 100
statusstringFilter by paid, pending or refunded
cursorstringOpaque value from the previous response

The response contains an orders array and a next_cursor field when more results exist.
