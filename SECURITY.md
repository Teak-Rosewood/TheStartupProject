# Security policy

## Reporting a vulnerability
Email **security@YOUR-DOMAIN** (replace this address when you fork; see `docs/startup/04-security-baseline.md`). Do not open a public issue for a vulnerability.

Include what you found, how to reproduce it, and the impact. We acknowledge reports within 3 business days and aim to fix or mitigate critical issues within 14 days. We will credit you if you want.

Please do not access other people's data, degrade the service, or run automated scanners against production without written permission.

## Supported versions
Only the latest commit on `main` is supported.

## For forks of this kit
Before launch, set a real security contact here, publish `/.well-known/security.txt` on your site, and enable GitHub private vulnerability reporting.
